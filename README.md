# PDF RAG Chatbot 📄

A Retrieval-Augmented Generation (RAG) application that allows users to ask questions about PDF documents.

## Features
- PDF document loading and processing
- Text chunking and vector embeddings
- ChromaDB vector storage
- Semantic search and retrieval
- Groq-powered LLM responses
- Streamlit chat interface

## Tech Stack
- Python
- LangChain
- ChromaDB
- Hugging Face Embeddings
- Groq LLM
- Streamlit

## Use Case
Upload a PDF and ask questions in natural language. The chatbot retrieves relevant document sections and generates context-aware answers.
